# 🌟 NGO App - Complete NGO Management System

A comprehensive mobile application built with React Native and Firebase for managing NGO operations, members, donations, events, and e-commerce.

## 📱 App Overview

NGO App is a full-featured management system designed for non-profit organizations. It provides separate interfaces for Admins, Working Members, and Regular Members with role-based access control.

## ✨ Features

### 👑 Admin Features
- **Dashboard** - Real-time KPI cards, charts (Member Growth, Revenue, Donations)
- **Member Management** - Full CRUD, search, filter, approve/suspend/delete
- **Working Member Management** - Level tracking (Bronze/Silver/Gold/Platinum), promotion management, commission tracking
- **E-Commerce Management** - Product CRUD, orders management, inventory tracking
- **Finance Management** - Donations, commissions, reports, transaction history
- **Event Management** - Create/edit/delete events, image upload, registration tracking
- **Notice & Complaint Management** - Notices, complaints, suggestions with priority levels
- **Company Profile Management** - Edit company details, social media, working hours

### 👥 Member Features
- **Dashboard** - View stats, recent activities, quick actions
- **Profile** - Edit profile, upload photo (Base64), view membership details
- **ID Card** - Digital ID card with share and download options
- **Certificate** - Auto-generated donation certificates with share/download
- **E-Commerce Shopping** - Browse products, add to cart, checkout with payment options
- **Cart & Checkout** - Full shopping experience with order summary
- **My Orders** - Track order status (pending/processing/completed/cancelled)
- **Events** - View and register for events with capacity tracking
- **Notice & Complaint** - View notices, submit complaints and suggestions
- **Company Profile** - View NGO details, board members, social media
- **Donation** - Make donations with auto-generated certificates

### 👷 Working Member Features
- **Dashboard** - View stats, registered members, commission earned
- **Profile** - View profile details
- **Member Registration** - Register new members
- **Commission Tracking** - View commission earned and history
- **Promotion Tracking** - Track promotion eligibility and status
- **E-Commerce** - Browse and buy products
- **Events** - View and register for events
- **Notice & Complaint** - View notices, submit complaints/suggestions

## 🛠️ Tech Stack

- **Frontend**: React Native (Expo)
- **Navigation**: React Navigation (Stack + Bottom Tabs)
- **Backend**: Firebase (Auth, Firestore, Storage)
- **Charts**: React Native Chart Kit
- **Icons**: Material Icons (@expo/vector-icons)
- **Image Picker**: Expo Image Picker
- **Styling**: React Native StyleSheet
